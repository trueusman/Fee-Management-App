# 💰 Fee Management App

A modern and responsive **Fee Management System** built using HTML, CSS, and JavaScript.  
It helps manage students, track monthly fees, generate receipts, and view financial reports in a simple dashboard interface.

---

## 🚀 Features

- 👨‍🎓 Add, view, and delete student records  
- 💳 Manage monthly fee payments (Paid / Partial / Unpaid)  
- 🧾 Generate and print professional receipts  
- 📊 Dashboard with real-time statistics  
- 🔍 Search and filter students & fee records  
- 📅 Monthly fee tracking system  
- 💾 LocalStorage support (data saved in browser)  
- 📱 Fully responsive design (mobile + desktop)

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Modern UI with variables & responsive design)  
- JavaScript (Vanilla JS)  
- LocalStorage (for data persistence)  
- Font Awesome (icons)  
- Google Fonts (Outfit)
